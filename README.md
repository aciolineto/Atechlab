# Atechlab — página simples

Abra index.html no navegador. Não precisa instalar nada, executar comandos ou ter conexão com a internet.

## Arquivos

- index.html: textos, menu, projetos, responsáveis e lista de extensionistas.
- styles.css: cores, tamanhos, espaçamentos e ajustes para celular.
- script.js: configuração opcional do endereço do sistema.
- logo.svg: logo da fábrica.

## Como editar

1. Para alterar um texto, encontre-o em index.html e substitua o conteúdo entre as tags.
2. Para adicionar um projeto, copie um bloco <article class="cartao">...</article> e altere o título e a descrição.
3. Para adicionar um extensionista, inclua <li>Nome completo</li> na lista.
4. Para mudar as cores, edite os códigos em styles.css: azul-marinho #0b1830, branco #ffffff e laranja #f97316.
5. Para configurar o acesso, preencha enderecoDoSistema em script.js. Enquanto estiver vazio, o link leva ao aviso na própria página.
6. Salve o arquivo e atualize a página no navegador.

O código tem comentários para identificar cada parte. A página usa HTML, CSS e apenas uma configuração simples em JavaScript. Não usa bibliotecas, fontes externas, animações ou ferramentas de compilação.
